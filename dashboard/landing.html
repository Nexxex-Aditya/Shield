Get Started in 60 Seconds

From zero to running pipelines with three commands.

# Initialize project
$ python shield_cli.py init my-project
$ cd my-project

# Add your AI model
$ python shield_cli.py models add openai sk-your-key

# Compile a pipeline from description
$ python shield_cli.py compile "Monitor GitHub PRs and post summaries to Slack"

# Start the server + dashboard
$ python shield_cli.py server
# → http://localhost:8000

# Or deploy with Docker
$ python shield_cli.py deploy --build --detach
